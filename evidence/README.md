[`live-fictional-safety-case.json`](live-fictional-safety-case.json) is the HTTP 200 response from the hosted demo on 29 September 2026, using a fictional enquiry about sparks and a gas smell in Pontypridd. It records the Nebius-hosted Nemotron extraction and the application's separate deterministic assessment. The route is `ESCALATE`; `messageSent` and `bookingCreated` are both `false`.

The model's suggested reply is untrusted text. The application displays it for review but uses fixed checks to produce the human-only handoff. This single example demonstrates behaviour, not accuracy, reliability at scale, or use with a real customer.
